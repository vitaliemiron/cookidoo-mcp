# Support

Choose the channel that matches what you need so account data stays safe and
answers remain useful to other users.

## Setup and usage questions

Start a
[Q&A Discussion](https://github.com/vitaliemiron/cookidoo-mcp/discussions/categories/q-a)
for help connecting an MCP client, understanding a tool, or choosing a safe
workflow.

Before posting:

1. Read the [getting-started guide](https://vitaliemiron.github.io/cookidoo-mcp/docs/).
2. Search existing
   [Discussions](https://github.com/vitaliemiron/cookidoo-mcp/discussions) and
   [issues](https://github.com/vitaliemiron/cookidoo-mcp/issues).
3. Remove all credentials, cookies, account identifiers, private recipes, and
   upload signatures from logs or screenshots.

Useful details include your operating system, Python version, MCP client,
installation method, the tool being called, the exact sanitized error, and
whether restarting the long-lived MCP process changed the result.

## Bugs and API regressions

- Use the [bug report
  form](https://github.com/vitaliemiron/cookidoo-mcp/issues/new?template=bug-report.yml)
  for reproducible project defects.
- Use the [Cookidoo API regression
  form](https://github.com/vitaliemiron/cookidoo-mcp/issues/new?template=api-regression.yml)
  when a previously working endpoint, response, or authentication flow changes.

Cookidoo's endpoints are undocumented and may change without notice. A
sanitized response shape or failed workflow link is more useful than repeated
full logs.

## Feature ideas

Use the [feature request
form](https://github.com/vitaliemiron/cookidoo-mcp/issues/new?template=feature-request.yml)
for a concrete capability. Use
[Ideas](https://github.com/vitaliemiron/cookidoo-mcp/discussions/categories/ideas)
when the problem or design is still exploratory.

The project covers Cookidoo recipe, image, shopping-list, and meal-planning
workflows. Store search and ordering belong in a separate store-specific MCP.

## Security and private data

Do not post security reports publicly. Send them through
[GitHub private vulnerability
reporting](https://github.com/vitaliemiron/cookidoo-mcp/security/advisories/new)
and follow [`SECURITY.md`](SECURITY.md).

This is a community-maintained, unofficial project. It cannot provide Cookidoo
account recovery, subscription, appliance, warranty, or official recipe
support; contact Cookidoo or Vorwerk for those services.
