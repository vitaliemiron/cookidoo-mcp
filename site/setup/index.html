Guided setup

Connect in a few clear steps.

Choose your computer and AI app. The wizard builds a configuration you can copy without putting your Cookidoo password in this page.

Step 1 of 4

Your password stays on your computer.

This page has no login or password fields and sends no form data.

Step 1 Which computer are you using? This changes the file path and terminal commands.

Step 2 Where will you talk to AI? Choose the app that should receive the Cookidoo tools.

Step 3 Choose your private file. Use an absolute path so your AI app can find the file from anywhere.

This is only a file location. Do not type your Cookidoo login or password here.

The generated file contains placeholders only

You will add your real login directly in a local text editor. Nothing entered in this wizard is submitted or saved.

Step 4

Your setup is ready to copy.

  1. 1

    Install the small command runner

    uv runs Cookidoo MCP in its own isolated environment.

    From the official uv installation guide. You may use one of its package-manager alternatives instead.

  2. 2

    Create and open the private file

    Paste these settings into that file and replace the login placeholders there:

    COOKIDOO_EMAIL=your-login
COOKIDOO_PASSWORD=your-password
COOKIDOO_COUNTRY=ro
COOKIDOO_LANGUAGE=en

    The ro/en locale defaults match the project’s existing international setup. Change both values together only to a valid Cookidoo country/language pairing for your account.

  3. 3

    Connect your AI app

  4. 4

    Restart and check the connection
