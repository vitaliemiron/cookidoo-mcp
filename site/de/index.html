Was im Hintergrund passiert

In den Schritten 2-4 werden Cookidoo MCP-Tools verwendet. Schritt 5 ist eine Übergabe: Ein Lebensmittelgeschäft MCP kann Produkte durchsuchen und eine Bestellung aufgeben.

  1. 1
    KI-Gespräch Finde eine Idee

    Beschreiben Sie ein Verlangen, ein Ziel oder teilen Sie einen Rezeptlink.

  2. 2
    Cookidoo MCP Machen Sie das Rezept Ihr

    Übersetzen Sie es, machen Sie die Schritte klarer und speichern Sie es.

  3. 3
    Cookidoo MCP Planen Sie Ihre Woche

    Fügen Sie die Mahlzeit zu dem Tag hinzu, der für Sie arbeitet.

  4. 4
    Cookidoo MCP Erstellung der Liste

    Sammeln Sie die Zutaten, während Sie den Rezeptkontext beibehalten.

  5. 5
    Weitere MCP Bestellen, wenn Sie bereit sind

    Geben Sie die Liste einer Automatisierung für Lebensmittelgeschäfte.

Warum es existiert

Eine Rezeptidee sollte nicht in Verwaltungsaufwand enden.

Der angenehme Teil ist die Auswahl und das Kochen von Speisen. Das Kopieren von Details, das Übersetzen von Schritten, das Aktualisieren eines Kalenders und das Wiederaufbauen einer Einkaufsliste sollten nicht übernommen werden.

  1. 01 Ideen kommen von überall her.Cookidoo, Blogs, Screenshots, Freunde und andere Sprachen.
  2. 02 Nützliche Rezepte brauchen klare Schritte.Vor allem, wenn man zum ersten Mal etwas kocht.
  3. 03 Eine Idee ist noch kein Plan.Die Mahlzeit braucht noch einen Tag und eine vollständige Zutatenliste.
  4. 04 Verbindungen können sich ändern.Tägliche Kontrollen helfen, Probleme zu erkennen, bevor sie Sie überraschen.

Was sie tun kann

Weniger kopieren. Mehr kochen.

Sie halten die Entscheidungen. Der Assistent hilft, sie von einer Idee in Cookidoo, Ihren Wochenplan und Ihre Zutatenliste zu tragen.

01/INSPIRATION

Verwandeln Sie "das sieht gut aus" in etwas, das Sie tatsächlich kochen können.

Bringen Sie ein Rezept aus Cookidoo oder einer anderen Quelle mit, übersetzen Sie es und passen Sie es Ihren Vorlieben an.

02/KLARITÄT

Machen Sie jeden Schritt einfacher für einen Anfänger.

Trennen Sie das Hinzufügen von Zutaten vom Mischen oder Kochen, so dass jede Aktion leicht zu befolgen ist.

03 / HEALTH

Bewegen Sie gesunde Absichten in eine praktische Woche.

Verwandeln Sie gute Absichten in Mahlzeiten, die Sie auf einem echten Wochenplan sehen können.

04 / FREI ZEIT

Hören Sie auf, die gleichen Informationen von Ort zu Ort zu bewegen.

Besprechen, anpassen, speichern, planen und sammeln Sie Zutaten aus einem Gespräch. Genaue Zeit gespart hängt von Ihrer Routine.

05 / GEFÜHRTES KOCHEN

Halten Sie die Thermomix-Einstellungen an den richtigen Schritt gebunden.

Zeit, Temperatur, Geschwindigkeit, Rückwärtsbewegung, Wiegen und unterstützte Kochmodi bleiben explizit.

06 / EIGENTUM

Fügen Sie das Bild hinzu, mit dem sich ein persönliches Rezept vollständig anfühlt.

Fügen Sie ein Foto hinzu, das Sie besitzen, so dass ein persönliches Rezept später leicht zu erkennen ist.

Tägliche Kontrollen suchen nach unterbrochenen Verbindungen.

Wenn sich Cookidoo ändert, erhalten Maintainer eine klare Warnung.
