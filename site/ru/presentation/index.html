07 / Ответственность

Когда неофициальный API меняется, тишина не является надежностью.

Cookidoo может изменяться без предварительного уведомления. Проект ежедневно проводит аутентифицированные тесты контрактов, создает проблему регрессии при отказе и закрывает ее после восстановления.
